# 実装調査

## 発動条件

- 外部 API、SDK、framework、NuGet、OS、言語仕様が実装判断へ影響する。
- 情報が更新される可能性がある。
- 原因候補が複数あり、ローカル証拠だけでは決められない。
- データ破損、セキュリティ、金銭に関わる高リスク変更である。

## 手順

1. 対象 source、設定、ログ、直接依存、関連 test を先に確認する。
2. ローカルだけで根拠が揃わない場合に外部調査へ切り替える。
3. 公式ドキュメント、公式仕様、公式 Issue、release notes、package repository、コミュニティ情報の順で確認する。
4. 技術調査では一次資料を優先する。
5. 外部情報を採用する場合は、対象症状との一致とローカル再現または検証結果を記録する。

## 制約

- ChatGPT の調査結果を無条件に採用せず、実装に必要な前提だけ確認する。
- ChatGPT が確認済みの一般調査を理由なく反復しない。
- 推測実装や暫定回避を既定動作にしない。
- 外部情報とローカル実測が矛盾する場合は、公式仕様または再現結果で裏づけられる方を優先する。
